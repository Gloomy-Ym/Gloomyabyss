# Ark Pixel Font 素材说明

- 上游项目：<https://github.com/TakWolf/ark-pixel-font>
- 素材版本：`v2026.08.11`
- 发布包：`12px proportional OTF`
- 许可证：SIL Open Font License 1.1，完整原文见同目录 `OFL.txt`

本目录保存未经修改的第三方字体发布包，包含拉丁、简体中文、繁体中文、香港字形、日文和韩文字体变体。目前这些文件仅作为备用素材归档，尚未注册到 `Gloomytale.yyp`，也未在游戏中使用。

需要启用字体时，应通过 GameMaker IDE 在 `fonts/` 下创建字体资源并选择所需变体，不要手动修改项目元数据。分发字体或制作衍生版本时，必须继续遵守 `OFL.txt`，并保留版权声明和许可证原文。
